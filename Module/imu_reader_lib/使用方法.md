# IMU Reader Lib 使用方法

## 编译

```bash
cd imu_reader_lib/build
cmake ..
make
```

产物：
- `libimu_reader_lib.a` — 静态库
- `imu_reader_example` — 示例可执行文件

要求：CMake ≥ 3.14，支持 C++17 的编译器（GCC 8+ / Clang 7+），Linux 系统。

---

## 快速开始

### 命令行运行示例

```bash
./imu_reader_example /dev/ttyUSB0          # 使用默认波特率 921600
./imu_reader_example /dev/ttyUSB0 115200   # 指定波特率
```

示例程序会打开串口、配置 IMU，然后循环打印加速度、角速度、欧拉角、四元数，按 Ctrl+C 退出。

### 集成到自己的项目

**CMakeLists.txt**：

```cmake
add_subdirectory(imu_reader_lib)
target_link_libraries(your_target imu_reader_lib)
```

**代码示例 — 基础用法**：

```cpp
#include "imu_reader.h"
#include <atomic>
#include <csignal>
#include <cstdio>

std::atomic<bool> running{true};

void on_signal(int) { running = false; }

int main() {
    signal(SIGINT, on_signal);
    signal(SIGTERM, on_signal);

    IMUReader reader;

    // 1. 打开串口
    if (!reader.open("/dev/ttyUSB0", 921600)) {
        fprintf(stderr, "Failed to open serial port\n");
        return 1;
    }

    // 2. 配置 IMU（启用所有数据输出）
    reader.configure();

    // 3. 注册数据回调
    reader.setCallback([](const IMUData &d) {
        // 判断本次更新了哪些数据
        if (d.updated & 1) {  // 加速度
            printf("Accel: x=%.4f y=%.4f z=%.4f\n",
                   d.accel.x, d.accel.y, d.accel.z);
        }
        if (d.updated & 2) {  // 角速度
            printf("Gyro:  x=%.2f y=%.2f z=%.2f\n",
                   d.gyro.x, d.gyro.y, d.gyro.z);
        }
        if (d.updated & 4) {  // 欧拉角
            printf("Euler: roll=%.2f pitch=%.2f yaw=%.2f\n",
                   d.euler.x, d.euler.y, d.euler.z);
        }
        if (d.updated & 8) {  // 四元数
            printf("Quat:  w=%.5f x=%.5f y=%.5f z=%.5f\n",
                   d.quat.w, d.quat.x, d.quat.y, d.quat.z);
        }
    });

    // 4. 主循环
    while (running) {
        if (reader.update() < 0) break;  // 读取出错则退出
    }

    reader.close();
    return 0;
}
```

## API 参考

### IMUReader

#### `bool open(const std::string &device, int baud_rate = 921600)`

打开串口设备。失败返回 `false`，成功返回 `true`。

- `device`：串口设备路径，如 `/dev/ttyUSB0`
- `baud_rate`：波特率，默认 921600。支持 9600 ~ 4000000

> 调用前会自动关闭已打开的端口，支持切换设备。

#### `bool configure()`

配置 IMU 传感器，依次执行：进入设置模式 → 启用加速度/角速度/欧拉角/四元数输出 → 设置 USB 输出通道 → 保存参数到 Flash → 返回正常模式。**必须在 `open()` 成功后调用。** 整个序列约需 400ms（含必要的硬件等待）。

配置期间任何步骤失败都会终止并打印错误信息到 stderr。

#### `void setCallback(IMUDataCallback cb)`

注册数据回调，类型为 `std::function<void(const IMUData&)>`。回调在 `update()` 内部触发，每收到一个完整且校验通过的数据帧就调用一次。

> 回调中避免执行耗时操作（磁盘 I/O、复杂计算），否则会影响 `update()` 的实时性。

#### `int update()`

从串口读取可用数据并喂给解析器。返回读取的字节数，-1 表示读取错误。非阻塞调用，如果没有新数据返回 0。

典型用法是在循环中调用，循环频率无需严格控制——`SerialPort` 的 100ms 超时保证 `read()` 不会长时间阻塞。

#### `bool sendCommand(const uint8_t *cmd, int len)`

向 IMU 发送原始命令字节。返回 `true` 表示全部字节写入成功。

命令格式：`0xAA <CMD> <PARAM> 0x0D`

常用命令：

| 命令 | 字节序列 | 说明 |
|------|----------|------|
| 进入设置模式 | `AA 06 01 0D` | 配置前必须发送 |
| 退出设置模式 | `AA 06 00 0D` | 配置完成后发送 |
| 启用加速度 | `AA 01 14 0D` | 在设置模式下发送 |
| 启用角速度 | `AA 01 15 0D` | 在设置模式下发送 |
| 启用欧拉角 | `AA 01 16 0D` | 在设置模式下发送 |
| 启用四元数 | `AA 01 17 0D` | 在设置模式下发送 |
| 保存参数 | `AA 03 01 0D` | 写入 Flash |
| 设置 USB 输出 | `AA 0A 00 0D` | 数据从 USB 串口输出 |

#### `void close()` / `bool isOpen()`

关闭串口 / 查询串口是否已打开。`IMUReader` 析构时不会自动关闭（`IMUReader::~IMUReader() = default`），但成员 `SerialPort` 的析构函数会调用 `::close(fd_)`，因此资源不会泄漏。

### IMUData 数据结构

```cpp
struct Vector3 {
    float x, y, z;
};

struct Quaternion {
    float w, x, y, z;
};

struct IMUData {
    uint8_t device_id;    // 设备 ID（通常固定）
    Vector3 accel;        // 加速度 (g)
    Vector3 gyro;         // 角速度 (°/s)
    Vector3 euler;        // 欧拉角：Roll, Pitch, Yaw (°)
    Quaternion quat;      // 四元数：W, X, Y, Z
    int updated;          // 位掩码：1=accel, 2=gyro, 4=euler, 8=quat
};
```

`updated` 字段用于判断当前回调携带了哪种数据。每次回调只设置对应位，`updated` 值只可能是 1、2、4、8 之一。

### 串口自定义配置

如果默认串口参数不满足需求，可绕过 `IMUReader` 直接使用 `SerialPort` + `IMUParser`：

```cpp
SerialPort sp;
sp.open("/dev/ttyUSB0", 921600);

IMUParser parser;
parser.setCallback([](const IMUData &d) { /* ... */ });

uint8_t buf[4096];
while (running) {
    int n = sp.read(buf, sizeof(buf));
    if (n > 0) parser.feed(buf, n);
    else if (n < 0) break;
}
sp.close();
```

`SerialPort` 额外提供 `flush()` 方法清空收发缓冲区。

## 常见问题

**Q: 为什么 `update()` 不阻塞？**
A: `SerialPort` 配置 `VMIN=0, VTIME=1`，使其为非阻塞读取。这样主循环不会被卡住，可以同时处理其他逻辑（如超时判断、信号处理等）。

**Q: 如何只启用部分传感器输出？**
A: 修改 `configure()` 的调用方式——直接调用对应的 `private` 方法需要改为 `public`，或者用 `sendCommand()` 手动发送命令。例如只启用加速度和角速度：

```cpp
reader.open("/dev/ttyUSB0");
reader.sendCommand((uint8_t[]){0xAA, 0x06, 0x01, 0x0D}, 4);  // 进入设置
std::this_thread::sleep_for(std::chrono::milliseconds(100));
reader.sendCommand((uint8_t[]){0xAA, 0x01, 0x14, 0x0D}, 4);  // 启用加速度
reader.sendCommand((uint8_t[]){0xAA, 0x01, 0x15, 0x0D}, 4);  // 启用角速度
reader.sendCommand((uint8_t[]){0xAA, 0x03, 0x01, 0x0D}, 4);  // 保存
std::this_thread::sleep_for(std::chrono::milliseconds(100));
reader.sendCommand((uint8_t[]){0xAA, 0x06, 0x00, 0x0D}, 4);  // 返回正常
```

**Q: 数据更新频率是多少？**
A: 取决于 IMU 传感器的输出频率设置（通过 `configure()` 启用的参数均为传感器的默认频率），以及串口波特率。波特率 921600 下，4 种数据类型 × 约 20 字节/帧 ≈ 需要足够带宽。若丢帧可检查波特率是否足够、回调是否耗时。

**Q: 可以在嵌入式 Linux 上使用吗？**
A: 可以，只要系统支持 termios 和 C++17 标准库即可（如 Buildroot/Yocto 构建的系统）。
