# 四足机器人 IK + MIT 位控 - 使用说明书

---

## 1. 系统概述

基于逆运动学（IK）+ 复合摆线轨迹 + MIT 位置控制的四足机器人遥控方案。

| 特性 | 说明 |
|---|---|
| 轨迹规划 | 复合摆线（cycloid）足端轨迹，位置/速度连续 |
| 运动学 | 3-DOF 腿 FK/IK + 雅可比 Jᵀ |
| 步态 | Trot 对角小跑（duty=0.6），四腿同时着地检测 |
| 控制模式 | MIT 模式（位置 + 刚度 + 阻尼 + 可选力矩前馈） |
| 控制频率 | 200 Hz |
| 遥控 | Xbox 手柄，通过 ROS2 joy_node |

### 坐标系

| 坐标系 | X | Y | Z |
|---|---|---|---|
| 机身 (Body) | 前方 | 左方 | 上方 |
| 髋关节 (Hip) | 前方 | 左方 | 上方 |

### 关节约定（右手定则）

| 序号 | 名称 | 旋转轴 | 正方向效果 |
|---|---|---|---|
| 0 | 髋侧摆 ABD | +X | 足端向 +Y（左）移动 |
| 1 | 髋俯仰 HIP | +Y | 足端向 -X（后）移动 |
| 2 | 膝俯仰 KNEE | +Y | 负值 = 膝前弯，0 = 伸直 |

### 腿编号

| 编号 | 名称 |
|---|---|
| 0 | LF 左前 |
| 1 | RF 右前 |
| 2 | LB 左后 |
| 3 | RB 右后 |

## 3. 编译

### 3.1 依赖

```bash
sudo apt install cmake g++ libspdlog-dev libfmt-dev \
    pybind11-dev python3-dev python3-pyserial \
    ros-humble-joy ros-humble-rclcpp ros-humble-sensor-msgs
```

### 3.2 构建

```bash
cd Dog_VMC
source /opt/ros/humble/setup.bash

# 首次构建 motors
cd Module/motors && mkdir -p build && cd build
cmake .. && make -j$(nproc)
cd ../../..

# colcon 构建全部 ROS2 包
colcon build
```

## 4. 上电准备

### 4.1 手柄配置（Orange Pi）

**安装与驱动**

```bash
sudo apt install joystick ros-humble-joy
```

**8BitDo Ultimate 2C 模式切换**

手柄必须工作在 X-input 模式才会生成 `/dev/input/js0` 设备：

```
关机 → 按住 Start+X → 插USB → 松手
```

**USB 端口**

必须插 USB 2.0/3.0 口（蓝色），Orange Pi 的 USB 1.1 口（`ohci-platform`）会导致手柄降级为键盘/鼠标模式。确认：

```bash
ls /dev/input/js0        # 必须存在
jstest /dev/input/js0    # 推摇杆看数值
```

**启动 joy_node**

```bash
ros2 run joy joy_node
# 另开终端验证
ros2 topic echo /joy     # 操作手柄应有数据
```

无数据排查：`sudo dmesg | grep -i "8bitdo\|input"` 确认手柄被正确识别为游戏手柄而非键盘。

### 4.2 CAN 配置（开机自启）

```bash
sudo tee /etc/systemd/system/can-setup.service << 'EOF'
[Unit]
Description=Setup CAN
After=multi-user.target
[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/bin/bash -c 'for i in 0 1 2 3; do ip link set can$i type can bitrate 1000000; ip link set up can$i; done'
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now can-setup.service
ip link show type can   # 验证全部 UP
```

```bash

ros2 run quad_control quad_control &
```

## 6. 遥控操作

| 按键 | 功能 |
|---|---|
| RB (btn 5) | 使能（S 曲线 → 趴下） / 再次 → 失能急停 |
| B (btn 1) | 站立 ↔ 趴下 |
| A (btn 0) | 站立 ↔ Trot（从 Trot 退出需先松摇杆） |
| 左摇杆上下 | Trot: 前进/后退（步长 0~0.15m） |
| 左摇杆左右 | Trot: 横移（±0.06m） |
| 右摇杆左右 | Trot: 旋转（±0.04m 切线摆线） |
| RT (axis 5) | 站立姿态: 升高机身 |
| LT (axis 2) | 站立姿态: 降低机身 |
| 十字键上下 | 站立姿态: 调抬腿高度 ±0.01m（0.01~0.10m） |

### 状态机

```
DISABLED ──RB──→ CROUCH ──B──→ STANDING ──A──→ TROTTING
   ↑                │            │              │
   └──────RB────────┴────RB──────┴──────RB──────┘
                   └──A──→ Trot   B→趴下    A→站立(四腿着地时)
```

## 9. 常见问题

### 电机报 0x07

DRV 芯片故障。断电重启，检查电机线松动。反复出现则驱动板可能有问题。

### 电机没力

确认 `init_motor()` 后电机已在 MIT 模式且 ENABLED。`lock_motor()` = CMD_ENABLE，`unlock_motor()` = CMD_DISABLE。

### 使能后突变

S 曲线读取当前关节角作为起点做插值，不会突变。如有问题检查 IK 参数是否正确。

### Trot ↔ 站立切换

A 键从 Trot 退出需先松摇杆（原地踏步），等四腿同时着地（~0.4s）后自动切换。

## 10. API 参考

### Python

```python
import kinematics_py as vmc

# 创建运动学模型
kin = vmc.LegKinematics(L1, L2, dx, dy)  # thigh, calf, dx, dy

# 正向运动学
foot = kin.forward([q_abd, q_hip, q_knee])

# 逆向运动学
q = kin.inverse(vmc.Vec3(x, y, z))

# 足端力 → 关节力矩（重力前馈）
tau = kin.foot_force_to_torques(q, vmc.Vec3(0, 0, fz))
```

### C++

```cpp
#include "kinematics/leg_kinematics.h"
#include "kinematics/types.h"
using namespace vmc;

LegKinematics::Params p{L1, L2, dx, dy};
LegKinematics kin(p);

Vec3 foot = kin.forward(q);           // FK
auto q = kin.inverse(Vec3(x,y,z));     // IK
auto tau = kin.footForceToTorques(q, force);  // JT * F
```
