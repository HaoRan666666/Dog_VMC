## 1. 系统概述

本方案为 12 自由度四足机器人提供完整的**位置控制**解决方案，核心特点：

| 特性 | 说明 |
|---|---|
| **轨迹规划** | 复合摆线曲线，保证足端位置、速度、加速度连续平滑 |
| **步态调度** | 支持 Trot / Walk / Bound / Pace / Stand 五种步态 |
| **平衡控制** | 虚拟模型控制（VMC），将虚拟力螺旋分配到支撑腿 |
| **状态估计** | IMU 互补滤波 + 腿部里程计 |
| **控制模式** | MIT 模式（位置 + 速度 + 刚度 + 阻尼 + 力矩前馈） |
| **控制频率** | 200 Hz（可配置） |
| **对外接口** | C++ 库 + Python 绑定 |

### 1.1 坐标系约定

| 坐标系 | X | Y | Z |
|---|---|---|---|
| **机身坐标系 (Body)** | 前方 | 左方 | 上方 |
| **髋关节坐标系 (Hip)** | 前方 | 左方 | 上方 |
| **世界坐标系 (World)** | 前方 | 左方 | 上方 |

- 所有内部计算使用 **弧度 (rad)**、**米 (m)**、**秒 (s)**
- 角度显示可转换为度 (degree)，仅用于调试输出

### 1.2 关节约定（严格遵循右手定则 RHR）

每条腿 3 个关节，**全部遵循右手定则**（拇指指向旋转轴正方向，四指弯曲方向为正旋转方向）：

| 序号 | 名称 | 符号 | 旋转轴 | 右手定则正方向 |
|---|---|---|---|---|
| 0 | 髋侧摆 | ABD | 髋坐标系 **+X** 轴（前） | 拇指指前，四指从 +Y 弯向 +Z → **足端向 +Y（左）移动** |
| 1 | 髋俯仰 | HIP | 髋坐标系 **+Y** 轴（左） | 拇指指左，四指从 +Z 弯向 +X → **足端向 -X（后方）移动** |
| 2 | 膝俯仰 | KNEE | 髋坐标系 **+Y** 轴（左） | 同上，负角度 → 小腿向前弯（膝前弯），0 为完全伸直 |

关键结论：
- **髋俯仰正角度 → 足端向后，负角度 → 足端前伸**。步态中摆动腿前伸需要负髋角。
- **膝关节负角度 → 膝前弯**（膝盖在髋后方），0 表示完全伸直（机械限位处通常 < 0）。
- **侧摆正角度 → 足端向左**（四指从 +Y 弯向 +Z）。对右腿需用负侧摆角才能将足端向外侧伸。

零位定义（q = [0, 0, 0]）：腿完全伸直竖直下垂，足端位于髋关节正下方 (0, 0, -(L1+L2))。

### 1.3 腿编号

| 编号 | 名称 | 含义 |
|---|---|---|
| 0 | LF | 左前腿 |
| 1 | RF | 右前腿 |
| 2 | LB | 左后腿 |
| 3 | RB | 右后腿 |

## 2. 架构设计

### 2.1 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      QuadrupedController                     │
│  ┌─────────────┐  ┌────────────┐  ┌──────────────────┐      │
│  │  GaitGenerator │  │TrajectoryPlanner│  │ BalanceController│  │
│  │  (步态调度)    │  │ (复合摆线)    │  │   (VMC 平衡)    │      │
│  └──────┬──────┘  └──────┬─────┘  └────────┬─────────┘      │
│         │                │                  │                 │
│  ┌──────┴────────────────┴──────────────────┴─────────┐      │
│  │                 LegKinematics × 4                    │      │
│  │              (逆运动学 + 雅可比 Jᵀ)                  │      │
│  └────────────────────────┬───────────────────────────┘      │
│                           │                                   │
│  ┌────────────────────────┴───────────────────────────┐      │
│  │               StateEstimator                         │      │
│  │         (IMU 互补滤波 + 里程计)                      │      │
│  └────────────────────────────────────────────────────┘      │
└─────────────────────────────────────────────────────────────┘
         │                                      ↑
         ▼                                      │
   RobotControlCommand                    IMU + Motor Feedback
   (12× MIT 指令)                         
         │                                      
         ▼                                      
    Motor Drivers (CAN/CANFD)                   
```

### 2.2 控制流水线

每个控制周期（5ms / 200Hz）执行以下步骤：

```
1. IMU 数据输入 → StateEstimator.updateImu()
2. 步态相位更新 → GaitGenerator.update()
3. 相位切换检测 → 记录摆动/支撑起始位置
4. 足端轨迹规划 → TrajectoryPlanner (复合摆线)
5. 逆运动学求解 → LegKinematics.inverse()
6. VMC 虚拟力计算 → BalanceController.computeVirtualWrench()
7. 支撑力分配 → BalanceController.solveFootForces()
8. 力矩转换 → LegKinematics.footForceToTorques() (Jᵀ)
9. 指令组装 → RobotControlCommand (MIT 模式)
10. 里程计更新 → StateEstimator.updateOdometry()
```

### 2.3 摆动相与支撑相

| 相位 | 控制策略 | 说明 |
|---|---|---|
| **摆动相** | 高刚度 PD 位置跟踪 | 复合摆线轨迹 → IK → 关节角 → MIT (high kp/kd) |
| **支撑相** | 低刚度位置保持 + VMC 力矩前馈 | 线性轨迹 → 位置指令 + VMC 力矩前馈 → MIT (low kp/kd + FF) |

## 4. 编译与安装

### 4.1 依赖项

| 依赖 | 用途 | 最低版本 |
|---|---|---|
| CMake | 构建系统 | 3.16 |
| GCC / Clang | C++17 编译器 | GCC 8+ |
| spdlog | 日志（电机驱动依赖） | 1.9.x |
| pybind11 | Python 绑定（可选） | 2.9.x |
| Python 3 | Python 接口 | 3.10+ |

### 4.2 编译步骤

```bash
# 1. 安装依赖（Ubuntu 22.04）
sudo apt install cmake g++ libspdlog-dev pybind11-dev python3-dev

# 2. 进入控制器目录
cd Dog_VMC/Controller

# 3. 创建构建目录
mkdir -p build && cd build

# 4. 配置（含 Python 绑定和测试）
cmake .. -DBUILD_PYTHON_BINDINGS=ON -DBUILD_TESTS=ON

# 5. 编译
make -j$(nproc)

# 6. 运行测试
./test_core
```

### 4.3 编译选项

| 选项 | 默认值 | 说明 |
|---|---|---|
| `BUILD_PYTHON_BINDINGS` | ON | 构建 pybind11 Python 模块 |
| `BUILD_TESTS` | OFF | 构建测试可执行文件 |

### 4.4 Python 模块安装

编译完成后，将 `.so` 文件路径加入 `PYTHONPATH`，或拷贝到项目目录：

```bash
# 方式 1：临时设置
export PYTHONPATH=/path/to/Dog_VMC/Controller/build:$PYTHONPATH

# 方式 2：在 Python 中导入
import sys
sys.path.insert(0, '/path/to/Dog_VMC/Controller/build')
import vmc_controller_py as vmc
```

## 5. 关键参数配置

### 5.1 机器人物理参数 (`RobotParams`)

```python
params = vmc.RobotParams()

# ─── 机身尺寸 ───
params.body_length = 0.45           # 机身前后长度 (m)
params.body_width = 0.25            # 机身左右宽度 (m)
params.body_height = 0.05           # 机身厚度 (m)
params.body_mass = 5.0              # 整机质量 (kg)

# ─── 腿部尺寸 ───
params.thigh_length = 0.20          # 大腿长度 (m)
params.calf_length = 0.20           # 小腿长度 (m)

# ─── 髋关节位置（机身坐标系） ───
params.hip_offset_x_front = 0.15    # 前腿髋 X 偏移 (m)
params.hip_offset_x_rear = -0.15    # 后腿髋 X 偏移 (m)
params.hip_offset_y = 0.12          # 髋 Y 偏移 (m)

# ─── 标称站立高度 ───
params.nominal_stand_height = 0.25  # 髋到地面距离 (m)
```

### 5.2 步态参数

```python
# 通过 set_config() 设置
ctrl.set_config(
    vmc.GaitType.TROT,      # 步态类型
    step_length=0.06,       # 步长 (m)
    step_height=0.04,       # 抬腿高度 (m)
    swing_kp=80.0,          # 摆动腿位置刚度
    swing_kd=5.0,           # 摆动腿速度阻尼
    stance_kp=30.0,         # 支撑腿位置刚度
    stance_kd=3.0,          # 支撑腿速度阻尼
)
```

### 5.3 步态参数指南

| 参数 | 推荐范围 | 调参建议 |
|---|---|---|
| `step_length` | 0.03 ~ 0.12 m | 越长速度越快，但需确保在工作空间内 |
| `step_height` | 0.02 ~ 0.08 m | 太低易擦地，太高降低稳定性 |
| `swing_kp` | 60 ~ 150 | 越高跟踪越准，但可能引起振荡 |
| `swing_kd` | 2 ~ 10 | 提供阻尼，抑制振荡 |
| `stance_kp` | 20 ~ 60 | 越低越柔顺，过高会与 VMC 力矩冲突 |
| `stance_kd` | 1 ~ 5 | 配合 kp 使用 |

### 5.4 VMC 平衡增益 (`BalanceController::Gains`)

```cpp
BalanceController::Gains bg;
// 质心水平速度跟踪
bg.kp_com_x = 30.f;   bg.kd_com_x = 15.f;
bg.kp_com_y = 30.f;   bg.kd_com_y = 15.f;

// 质心高度跟踪
bg.kp_com_z = 500.f;  bg.kd_com_z = 100.f;

// 姿态跟踪
bg.kp_roll = 200.f;   bg.kd_roll = 40.f;
bg.kp_pitch = 200.f;  bg.kd_pitch = 40.f;
bg.kd_yaw = 30.f;

// 力分布约束
bg.friction_mu = 0.7f;          // 摩擦系数
bg.max_foot_force_z = 80.f;     // 最大法向力 (N)
bg.min_foot_force_z = 5.f;      // 最小法向力 (N)
bg.max_foot_force_xy = 30.f;    // 水平力限幅 (N)
bg.reg_lambda = 0.01f;          // 正则化系数
```

## 6. API 参考

### 6.1 C++ API

#### QuadrupedController（主入口）

```cpp
// 构造函数
QuadrupedController(const RobotParams& params = {});
QuadrupedController(const RobotParams& params, const Config& config);

// 设置配置
void setConfig(const Config& cfg);

// 设置运动指令
void setMotionCommand(const RobotMotionCommand& cmd);

// IMU 数据输入
void updateImu(float dt, const Vec3& accel, const Vec3& gyro);

// 设置关节反馈
void setJointFeedback(const RobotJointState& state);

// 执行一次控制迭代（核心函数）
RobotControlCommand step(float dt);

// 状态查询
const BodyState& bodyState() const;
const GaitState& gaitState() const;
```

#### LegKinematics

```cpp
// 正向运动学：关节角 → 足端位置
Vec3 forward(const std::array<float, 3>& q) const;

// 逆向运动学：足端位置 → 关节角
std::array<float, 3> inverse(const Vec3& foot_pos,
    const std::array<float, 3>& q_prev = {0, 0, 0}) const;

// 足端力 → 关节力矩（Jᵀ 转换）
std::array<float, 3> footForceToTorques(
    const std::array<float, 3>& q, const Vec3& foot_force) const;
```

#### TrajectoryPlanner（静态函数）

```cpp
// 复合摆线位置曲线 [0, 1]

static float compositeCycloidVel(float s);
// 抬腿高度曲线 [0, 1]
static float liftCurvePos(float s);
```

### 6.2 Python API

```python
import vmc_controller_py as vmc

# ─── 创建控制器 ───
params = vmc.RobotParams()
ctrl = vmc.QuadrupedController(params)

# ─── 设置步态参数 ───
ctrl.set_config(
    vmc.GaitType.TROT,  # 步态类型
    step_length=0.06,   # 步长 (m)
    step_height=0.04,   # 抬腿高度 (m)
    swing_kp=80.0,      # 摆动刚度
    swing_kd=5.0,       # 摆动阻尼
    stance_kp=30.0,     # 支撑刚度
    stance_kd=3.0,      # 支撑阻尼
)

# ─── 设置运动指令 ───
motion = vmc.RobotMotionCommand()
motion.target_velocity = vmc.Vec3(0.15, 0.0, 0.0)  # 前进 0.15 m/s
motion.target_yaw_rate = 0.0                         # 无偏航
motion.target_body_height = 0.0                      # 标称站立高度
ctrl.set_motion_command(motion)

# ─── 控制循环 ───
dt = 0.005  # 200 Hz
while running:
    # 读取 IMU
    accel = vmc.Vec3(ax, ay, az)
    gyro = vmc.Vec3(gx, gy, gz)
    ctrl.update_imu(dt, accel, gyro)

    # 运行一步控制
    commands = ctrl.step(dt)

    # 发送到电机
    for leg in range(4):
        for joint in range(3):
            cmd = commands.legs[leg][joint]
            motor.motor_mit_cmd(
                cmd.position, cmd.velocity,
                cmd.kp, cmd.kd,
                cmd.feedforward_torque
            )
```

### 7.3 自定义 C++ 控制循环

```cpp
#include "vmc_controller/quadruped_controller.h"
using namespace vmc;

int main() {
    // 配置机器人参数
    RobotParams params;
    params.thigh_length = 0.20f;
    params.calf_length = 0.20f;
    params.body_mass = 5.0f;

    // 创建控制器
    QuadrupedController ctrl(params);
    QuadrupedController::Config cfg;
    cfg.gait_type = GaitType::TROT;
    cfg.step_length = 0.06f;
    cfg.step_height = 0.04f;
    ctrl.setConfig(cfg);

    // 设置运动指令
    RobotMotionCommand motion;
    motion.target_velocity = {0.15f, 0.f, 0.f};  // 前进
    ctrl.setMotionCommand(motion);

    // 控制循环
    float dt = 0.005f;  // 200 Hz
    while (running) {
        // 读取 IMU（由用户实现）
        Vec3 accel = read_accelerometer();
        Vec3 gyro = read_gyroscope();
        ctrl.updateImu(dt, accel, gyro);

        // 读取电机反馈（由用户实现）
        RobotJointState joint_state = read_joint_feedback();
        ctrl.setJointFeedback(joint_state);

        // 执行一步控制
        auto commands = ctrl.step(dt);

        // 发送 MIT 指令到电机（由用户实现）
        send_to_motors(commands);

        // 等待下一周期
        sleep_until_next_cycle(dt);
    }
}
```

## 8. 遥控控制

提供两种遥控方案：ROS2 版本（使用 joy_node）和独立版本（使用 pygame）。

### 8.1 摇杆映射（Xbox 手柄默认）

| 操作 | 功能 |
|---|---|
| 左摇杆 **上下** | 前进/后退速度 vx |
| 左摇杆 **左右** | 左右平移速度 vy |
| 右摇杆 **左右** | 偏航角速度（原地转向） |
| 右摇杆 **上下** | 机身高度偏移 |
| 十字键 **上下** | 步态切换（Stand→Walk→Trot→Pace→Bound→循环） |
| **A** 键 | 使能（启动控制） |
| **B** 键 | 停止（电机卸力） |
| **X** 键 | 站立模式 |
| **Y** 键 | Trot 模式 |
| **LB** | 减小抬腿高度 |
| **RB** | 增大抬腿高度 |

### 8.2 ROS2 版本（推荐）

```bash
# 终端 1：启动手柄驱动
ros2 run joy joy_node

# 终端 2：启动四足遥控节点
cd Dog_VMC/Module/joy
python3 joy_control.py

# 仿真模式（无硬件）
python3 joy_control.py --sim

# 自定义参数
python3 joy_control.py --max-vx 0.2 --max-vy 0.1 --max-yaw 0.5
```

### 8.3 独立版本（无 ROS2）

```bash
pip install pygame
cd Dog_VMC/Module/joy
python3 joy_control_standalone.py
python3 joy_control_standalone.py --sim
```

### 8.4 安全保护

- **通信超时**：超过 0.3 秒未收到手柄信号，自动将目标速度置零（机器人不会失控）
- **急停**：按 B 键立即将全部电机锁止
- **死区过滤**：摇杆微小抖动（< 0.08）被忽略，避免误触发

## 9. 调试指南

### 8.1 开发顺序建议

按以下顺序逐步构建和调试：

```
1. 单关节电机测试 → 确认 12 个电机均可正常通信和控制
2. 关节编号与方向校准 → 确认各关节零位和正方向
3. 单腿 IK 测试 → 给定期望足端位置，观察关节角是否正确
4. 四腿站立 → 从趴下姿态插值到站立姿态
5. 起立/趴下 → 测试身体高度升降
6. 单腿抬腿测试 → 一次摆动一条腿，其余支撑
7. 原地踏步 → Trot 步态零速踏步
8. Trot 行走 → 低速度开始，逐渐加速
9. IMU 姿态补偿 → 加入平衡控制
10. 遥控控制 → 加入运动指令输入
```

### 8.2 关键数据记录

建议记录以下字段用于离线分析：

| 字段 | 说明 |
|---|---|
| `time` | 时间戳 |
| `q_des[0..11]` | 12 个目标关节角 |
| `q_actual[0..11]` | 12 个实际关节角 |
| `q_error[0..11]` | 关节跟踪误差 |

| `body_vel_x, body_vel_y` | 机身速度估计 |

### 8.3 重点观察曲线

| 曲线 | 目的 |
|---|---|
| `q_des` vs `q_actual` | 检查关节跟踪效果 |
| 足端 X-Z 轨迹 | 检查复合摆线轨迹是否连续平滑 |
| `roll / pitch` | 检查机身稳定性（应接近 0） |
| `loop_dt` | 确保控制周期稳定（≤ 5ms） |

### 8.4 常见调参问题

| 现象 | 可能原因 | 解决方向 |
|---|---|---|
| 机器人无法站立 | 关节零位不正确 | 重新标定各关节零位 |
| 行走时机身倾斜 | VMC 姿态增益不足 | 增大 kp_roll / kp_pitch |
| 摆动腿触地 | 抬腿高度不够或 IK 误差 | 增大 step_height 或检查 IK |
| 电机过热/过流 | 增益过大、振荡 | 降低 swing_kp / stance_kp |
| 足端打滑 | 摩擦锥约束太松 | 减小 friction_mu 或增大 min_foot_force_z |
| 步态不协调 | 相位偏移设置错误 | 检查步态相位定义 |

## 11. 零点标定

电机读数与运动学角度之间存在固定偏移。标定的目的就是确定这一偏移量：

$$q_\text{kinematic} = q_\text{motor\_raw} - q_\text{zero\_offset}$$

**机械限位问题**：由于机械结构限制，膝关节通常无法完全伸直（无法达到 $q_\text{knee} = 0$ 的位置）。这不影响控制——IK 自然会输出可达范围内的角度值。标定的关键是让电机读数与运动学角度正确对应。

### 10.1 标定方法一：单关节标定（推荐）

对每个关节单独标定，精度最高。步骤如下：

**步骤 1**：将目标关节移动到已知物理角度位置，用角度尺/水平仪测量。

**步骤 2**：记录该位置下的电机读数。

**步骤 3**：调用 `calibrate_joint()` 计算并设置偏移量。

**膝关节标定示例**（最关键的关节）：

```
机械限位处：大腿与小腿的内角 = 170°（即两连杆几乎但未完全伸直）
↓ 换算为运动学膝角（RHR，膝前弯，负角度 = 前弯）：
q_knee = -(π - 170° × π/180) = -(π - 2.967) = -0.175 rad

读取电机角度（限位处）：q_motor = 2.35 rad

偏移量 = 2.35 - (-0.175) = 2.525 rad
```

```python
# 记录 12 个关节的标定数据
ctrl.calibrate_joint(vmc.LegIndex.LF, vmc.JointIndex.ABD,  motor_reading=0.52, kinematic_angle=0.0)
ctrl.calibrate_joint(vmc.LegIndex.LF, vmc.JointIndex.HIP,  motor_reading=0.88, kinematic_angle=0.5)
ctrl.calibrate_joint(vmc.LegIndex.LF, vmc.JointIndex.KNEE, motor_reading=2.35, kinematic_angle=-0.175)
# ... 对其余 3 条腿重复
```

**髋侧摆标定**：将腿摆到竖直下垂位置（用量角器确认侧摆角 = 0），记录电机读数。

**髋俯仰标定**：将大腿摆到指定角度（如用水平仪确认大腿与垂直线夹角 = 30° = 0.524 rad，注意方向），记录电机读数。

### 10.2 标定方法二：参考姿态批量标定

将机器人放置在平整地面上，四条腿着地呈标准站立姿态，测量足端相对机身的位置，一次性计算全部 12 个偏移量。

```python
# 1. 将机器人放在平坦地面上，调整到标准站立姿态
# 2. 测量四个足端在机身坐标系中的位置 (x前, y左, z上)
foot_positions = [
    vmc.Vec3( 0.15,  0.14, -0.25),  # LF：前15cm, 左14cm, 髋下25cm
    vmc.Vec3( 0.15, -0.14, -0.25),  # RF：前15cm, 右14cm, 髋下25cm
    vmc.Vec3(-0.15,  0.14, -0.25),  # LB：后15cm, 左14cm, 髋下25cm
    vmc.Vec3(-0.15, -0.14, -0.25),  # RB：后15cm, 右14cm, 髋下25cm
]

# 3. 读取所有电机当前角度
raw_state = vmc.RobotJointState()
for leg in range(4):
    for joint in range(3):
        raw_state.legs[leg].position[joint] = motor_readings[leg][joint]

# 4. 批量标定
ctrl.calibrate_from_reference_pose(raw_state, foot_positions)
```

标定后检查各关节偏移量：

```python
offsets = ctrl.joint_zero_offsets()
for leg_name, leg_idx in [("LF",0), ("RF",1), ("LB",2), ("RB",3)]:
    abd_off = offsets[leg_idx][0]
    hip_off = offsets[leg_idx][1]
    knee_off = offsets[leg_idx][2]
    print(f"{leg_name}: abd_off={abd_off:+.3f}, hip_off={hip_off:+.3f}, knee_off={knee_off:+.3f}")
```

### 10.3 保存和加载标定数据

标定数据保存在 `RobotParams.joint_zero_offset` 中，应持久化到配置文件：

```python
import json

# 保存
offsets = ctrl.joint_zero_offsets()
# 转换为可序列化格式
data = [[[float(v) for v in row] for row in offsets]]
with open('calibration.json', 'w') as f:
    json.dump({"joint_zero_offset": data}, f, indent=2)

# 加载
with open('calibration.json', 'r') as f:
    calib = json.load(f)
ctrl.set_joint_zero_offsets(calib["joint_zero_offset"])
```

### 10.4 标定验证

标定完成后验证：

```python
# 将机器人放在已知姿态，用 IK 反算期望关节角
# 读取电机原始值 → 转为运动学角度 → 应与 IK 结果一致

# 例如：足端在髋正下方 0.25m
foot_target = vmc.Vec3(0.0, 0.0, -0.25)
q_expected = kin.inverse(foot_target)  # IK 结果

# 读取电机，转换到运动学空间
q_kin = ctrl.raw_to_kinematic(leg, joint, motor_reading)

# 误差应 < 0.05 rad (约 3°)
error = abs(q_kin - q_expected[joint])
assert error < 0.05, f"标定误差过大: {error:.3f} rad"
```

## 附录 A：复合摆线轨迹公式

### 水平方向（X-Y 平面）

位置：`x(s) = x₀ + L · (s − sin(2πs) / 2π)`
速度：`v(s) = (L / T) · (1 − cos(2πs))`

其中 `s = t / T_swing ∈ [0, 1]`。

特性：起点速度 = 0、终点速度 = 0，加速度连续，无冲击。

### 垂直方向（抬腿高度）

位置：`z(s) = z₀ + H · (1 − cos(2πs)) / 2`
速度：`v(s) = (H / T) · π · sin(2πs)`

特性：起点和终点高度为 0（着地），中点达到最大高度 H。

## 附录 B：VMC 力分配原理

虚拟模型控制将期望的机身运动转化为虚拟力螺旋 W = [F, τ] ∈ ℝ⁶：

- `F_x, F_y`：水平力，由机身速度误差的 PD 控制产生
- `F_z`：垂直力，包含重力补偿 + 高度误差 PD 控制
- `τ_x, τ_y`：横滚/俯仰力矩，由姿态误差的 PD 控制产生
- `τ_z`：偏航力矩，由偏航角速度误差产生

然后通过抓取矩阵 G 将 W 分配到 N 条支撑腿：

`f = Gᵀ · (G·Gᵀ + λI)⁻¹ · W`

其中每腿贡献 `[I₃; [p×]]` 到 G，`[p×]` 是足端位置的叉乘矩阵。

每腿的足端力 `f_i` 通过 `τ_i = Jᵀ · f_i` 转换为关节力矩，加上位置保持的 PD 项后，以 MIT 模式发送给电机。
